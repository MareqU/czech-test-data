Testovací data, která najdou chyby

Platná, hraniční i schválně chybná česká data pro ruční i automatické testy. Každá chyba má jméno a validátor vám řekne, proč hodnota neprošla.

Projde tohle vaším formulářem?

    Co generovat

      Kliknutím na hodnotu ji zkopírujete. Odkaz vrátí přesně tytéž hodnoty.

      Ověřit hodnotu

      Vložte jednu nebo víc hodnot, každou na řádek. Mezery se neořezávají – mezera navíc je také chyba.

        Totéž v automatických testech

        Knihovna pro TypeScript a JavaScript a příkazová řádka. Stejný seed dává stejné hodnoty jako tady.

        TypeScript
        Příkazová řádka

        Instalace: npm install --save-dev czech-test-data

        Vše běží ve vašem prohlížeči, nic se neodesílá. Data jsou jen pro testovací systémy: platné rodné číslo nebo telefon může patřit skutečnému člověku.
