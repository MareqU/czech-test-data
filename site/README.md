# Web tool (site/)

A static site for testers. The home page shows every identifier at once with a valid, an edge and an invalid value
to copy; each identifier page has one big generated value with its Czech explanation, variant chips (or the
generator's options for valid values), more values, the form-check kit ("Sada": every variant with the expected
outcome, as JSON for data-driven tests or CSV for Excel), a validator with the meaning of each reason, and the
equivalent code and CLI command. Seed and reference date are in the URL, so a link reproduces the same values.
Czech only. Everything runs in the browser; nothing is sent anywhere. No framework, no web fonts.

## Pages

- `/` – overview table of all identifiers (`src/home.ts`, `src/overview.ts`), the kit of one identifier on demand,
  the library on npm. Its values are written into the HTML at build time, so agents and search engines without
  JavaScript see real data; the script draws a fresh seed on load.
- `/rodne-cislo/`, `/ico/`, `/dic/`, `/cislo-uctu/`, `/iban/`, `/telefon/`, `/psc/`, `/ean/`, `/eic/` – one page
  per identifier with its own title, description, h1 and intro in the HTML (texts in `src/catalog.ts`, `page`), and
  the values of its default state (seed 1) prerendered, replaced by the script on load.

The HTML files are generated by `build/pages.ts` and written by the Vite plugin `build/plugin.ts` on every dev
start and build, together with `public/llms.txt` for AI agents (`build/llms.ts`) and every kit as
`public/data/<id>.json` (`build/prerender.ts`); they are in `.gitignore`, never
edit them. Identifier pages share `src/main.ts` and set `<body data-id>`, so their URL carries only the state
(mode, variant, seed, …). Links are relative, so the site works
from any path; canonical URLs, Open Graph tags, `sitemap.xml` and `robots.txt` use `SITE` (https://testovacidata.cz/).

Deployed by Netlify on every push to `main` (build settings in `netlify.toml` in the repository root), custom domain
set in the Netlify site's domain settings.

A new page is one more entry in `renderPages()`.

## Development

- Uses the package only through its public exports (`czech-test-data: file:..`), like a user from npm.
  Build the library first: `npm run build` in the repository root.
- The build fails when the library gets a variant or reason without a Czech text in `src/catalog.ts`.

```bash
npm run build            # in the repository root: dist/ for the site
cd site && npm ci
npm run dev              # local server, http://localhost:5173/ and /ico/ etc.
npm run check            # types (app, build, tests), lint (repo ESLint config), tests, production build
```

`tests/site.test.ts` runs the code snippet with Node and the CLI snippet against `../dist/cli.mjs` and checks that
both print exactly the values the page shows; it also checks every generated page (title, h1, description, links),
the kit and its exports, and runs the commands of `llms.txt`.
